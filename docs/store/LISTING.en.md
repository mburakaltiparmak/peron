## Product name
Peron

## Description (≤ 10,000 chars)
Forgot to stop a dev server? Hunting down "port 3000 is already in use"? Peron shows the ports open on your computer and the processes behind them on one screen — and closes the forgotten ones in one click.

For every port:
• Which process uses it, and who started it (e.g. VS Code → node)
• Which project folder it belongs to
• How long it has been open
• How much CPU, memory and disk it uses
• Whether it's reachable only from this PC or from the network

Press "Close" to free a port: Peron shows you the process, its command line and any other ports it holds, and ends it only after you confirm. Critical Windows processes are protected and can't be ended.

Peron runs in the system tray with a tiny footprint and reminds you about dev servers left running for hours. Closing the window unloads the UI from memory entirely.

No accounts, no ads, no telemetry. Port and process data never leave your device.

This is a beta — send feedback from the in-app Contact tab.

## Product features (≤ 200 each, up to 20)
- Lists open TCP/UDP ports and the owning process
- Shows who started the process and which project it belongs to
- Shows how long a port has been open and its resource usage
- Close ports with confirmation; system processes are protected
- Reminders for forgotten dev servers
- Runs in the system tray with minimal resources
- English and Turkish, light/dark theme, keyboard shortcuts
